# API Reference

Base URL: `http://localhost:4000/api/v1`
Swagger UI: `http://localhost:4000/api/docs`

## Auth
- `POST /auth/register`
- `POST /auth/login`
- `POST /auth/refresh`
- `GET  /auth/me`

## Resources
`/users`, `/organizations`, `/departments`, `/teams`, `/roles`,
`/permissions`, `/projects`, `/tasks`, `/comments`, `/approvals`,
`/notifications`, `/documents`, `/crm/leads`, `/finance/expenses`,
`/finance/budgets`, `/finance/invoices`, `/products`, `/gwash`,
`/audit`, `/dashboard/executive`
